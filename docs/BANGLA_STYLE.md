# Bangla writing guide (employee-facing text)

Everything employees see — the employee portal, Practice Lab explanations and messages, Work guides,
login / sign-up / password pages, employee emails and notifications — is written in Bangla.
The admin panel and the public website stay in English.

## Tone

* Write the way a friendly team lead would explain things to colleagues: natural, clear, short sentences.
  Never word-for-word or machine-translated ("Google Translate") Bangla, never stiff or bookish.
* Use **আপনি** (polite you). Use active, everyday verbs: "দেখুন", "চাপুন", "শুরু করুন", "জমা দিন".
* Keep the meaning of the original exactly; do not add or drop information.
* Keep a technical word in English when that is what employees actually say and see in the tools:
  video, clip, timeline, playhead, Submit, QA, CVAT, annotation, project code, Employee ID, email, password
  (Bangla script is fine too where it reads naturally, e.g. ভিডিও, ক্লিপ, টাইমলাইন).
* Button labels in the **production clipping tool** (Delete Clip, Task Error, Shortcuts, Speed, Source,
  Loop Current Segment, Realign Video, submit task, Submit & Next, Previous, Next) stay **in English
  exactly as in the real tool** — in the Practice Lab replica and when guides refer to them.
* Numbers, scores, times and dates may use Latin digits (85%, 02:15) — they are easier to scan.
  Work guides use Bangla digits for step numbers (ধাপ ১.২).
* Punctuation: use the Bangla full stop "।" at the end of Bangla sentences.
