How it works

  1. In Lark open the document → ⋯ → Download as → Word (or Markdown).
  2. Upload it here. Headings become sections and steps in the original order; each step keeps the original English text and its video link (original link, not re-hosted).
  3. The guide is created as a draft. In the editor, write the Bangla text of each step next to the original, set the video segments, add the Task Error examples the document/video shows, and verify every item.
  4. Publish when every item is verified.

Nothing is translated or invented automatically — the original document stays the source of truth.
